# PII Data Protection — Data Cleaning & Masking

## Project Overview

This project demonstrates data cleaning and Personally Identifiable Information (PII) masking techniques using Microsoft Excel.

The objective is to identify sensitive personal information, standardize data, and apply masking techniques to reduce the exposure of confidential information in structured datasets.

## Project Objectives

- Identify fields containing Personally Identifiable Information (PII).
- Apply data cleaning and standardization techniques.
- Mask sensitive information to reduce direct exposure.
- Preserve data structure and usability for analysis.
- Document the transformation process.

## Key Skills Demonstrated

- Data Cleaning
- PII Identification
- Data Masking
- Data Standardization
- Microsoft Excel
- Data Quality
- Basic Data Protection Practices

## Tools Used

- Microsoft Excel

## Data Privacy

This project uses synthetic or anonymized sample data for demonstration purposes.

No real customer records or confidential client information should be included in this repository.

## Project Scope

This is an educational portfolio project demonstrating practical data cleaning and PII masking techniques.

It does not represent a certified security audit or guarantee regulatory compliance.
